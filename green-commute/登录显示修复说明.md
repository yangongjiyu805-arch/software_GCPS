# GreenGo 登录界面显示修复（2026-10-20）

## 问题

成功登录后虽然页面逻辑将 `#login-page.hidden` 设置为 `true`，但样式 `.login-page { display:grid; }` 是作者 CSS，覆盖浏览器对 `[hidden]` 的默认隐藏样式，因此登录表单仍然显示。

## 修复

1. `app/static/style.css` 增加 `[hidden]{display:none!important}`，确保任何标记为 `hidden` 的页面和按钮都不会被组件样式覆盖。
2. `app/static/app.js` 通过 `showUser()` 统一在三种角色登录成功时更新用户名、头像及“退出”按钮；退出登录时恢复访客头像。
3. `app/static/index.html` 采用样式与脚本版本号，避免浏览器继续使用旧的缓存资源。
4. `tests/test_frontend_visibility.py` 新增三项回归检查。

## 验证范围

- `python -m pytest -q tests`：19 项通过（16 项原业务测试 + 3 项前端状态回归检查）。
- 使用 Chromium 浏览器实际执行 DOM 显示切换检查；接口响应由浏览器内模拟器提供（**不是**真实后端 HTTP 端到端验证）：访客初始页显示、居民/商户/管理员登录后表单隐藏且对应工作台显示、退出后重新显示登录表单，均通过，且无浏览器脚本错误。
- 全套后端集成测试仍通过，使用独立临时数据库；不会清空自带演示数据库。

## 已有 Anaconda 项目升级

在启动服务的 Anaconda Prompt 按 **Ctrl+C** 停止服务，然后到包含 `green-commute` 文件夹的**上一级目录**运行：

```bat
python -m zipfile -e "GreenGo-登录界面修复补丁.zip" .
cd green-commute
conda activate greengo
python -m pytest -q tests
set "JWT_SECRET=greengo-course-local-only-change-before-deployment"
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

重新打开主页并按 Ctrl+F5 强制刷新，观察登录、角色页面、退出三个状态。**补丁不包含数据库，不会改变已有业务数据。**
