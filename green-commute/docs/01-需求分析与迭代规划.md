# 实验一：需求分析与迭代规划

## 1. 项目背景与范围

本系统面向城市绿色出行激励场景，旨在为参与绿色出行的居民提供可理解、可追溯的积分奖励机制，并为商户及平台管理者提供兑换与清算的管理入口。课程原型只接收**模拟行程**，不接入公共交通卡、GPS、位置服务或真实碳交易平台，也不将模拟数据宣称为核证减排量。

## 2. 干系人和主要诉求

| 参与者 | 业务目标 | 核心使用场景 | 风险与约束 |
|---|---|---|---|
| 居民 | 出行获得合理积分、使用权益 | 登录、行程上报、查余额与流水、兑换 | 不重复计分，不被超扣，无账户串读 |
| 商户 | 公开商品库存、核销兑换 | 发布商品、处理订单 | 库存不能为负，履约必须明确 |
| 运营管理员 | 衡量参与量、核对清算 | 查询平台指标、清算商户积分 | 清算只允许已履约订单，重复清算无副作用 |
| 项目小组 | 可迭代、可验证和可复现 | UML建模、Git协作、自动测试 | 课程周期和资源有限 |

## 3. 用户故事地图

| 活动 | 发现/进入 | 执行业务 | 确认结果 | 未来增强 |
|---|---|---|---|---|
| 居民出行 | 登录、了解核算规则 | 提交模拟行程 | 查询发放结果、积分流水 | GPS核证、反作弊 |
| 居民兑换 | 浏览和筛选商品 | 原子扣分、扣库存 | 查看待履约/已核销订单 | 取消订单/退款 |
| 商户运营 | 登录商户界面 | 上架商品、查询订单 | 确认核销 | 商户报表与库存预警 |
| 平台管理 | 查看统计 | 重试事件、查看清算单 | 已履约订单结算 | 财务对账、人工稽核 |

MVP（第一期）的目标故事：居民登录 → 上报公交行程 → 计算减排及发分 → 查积分 → 商城兑换 → 商户核销 → 管理员清算。

## 4. 功能性需求（可追溯ID）

| ID | 需求 | 验收准则 | 重要性 |
|---|---|---|---|
| FR-01 | 登录注册及身份鉴别 | 错误密码401；居民可注册；JWT可访问受保护接口 | P0 |
| FR-02 | 角色权限控制 | 居民/商户/管理员各自仅访问授权资源 | P0 |
| FR-03 | 模拟行程上报 | 支持公交/地铁/骑行/步行，0.01—100km，最多2位小数 | P0 |
| FR-04 | 碳减排与积分核算 | 10km公交节省1.1kg并发11分；积分取整规则固定 | P0 |
| FR-05 | 行程/事件幂等性 | 重复行程不上双份积分；相同ID内容冲突返回409 | P0 |
| FR-06 | 积分账本 | 每一笔发放、消费留有类型、关联业务、正负积分、时间 | P0 |
| FR-07 | 积分商城 | 所有人可浏览商品和剩余库存 | P0 |
| FR-08 | 安全积分兑换 | 余额/库存不足拒绝；成功时库存和积分同事务扣减 | P0 |
| FR-09 | 商户商品/订单管理 | 商户可发布商品并核销所属商品订单 | P1 |
| FR-10 | 平台清算 | 兑换形成待清算单，已核销才可清算，重复操作幂等 | P1 |
| FR-11 | 平台汇总 | 可展示注册居民、行程、节约量、发分、订单等指标 | P1 |
| FR-12 | 事件重试 | Outbox 事件消费失败后保留，允许再次处理且不双记账 | P1 |

## 5. 非功能需求

- NFR-01 正确性：积分使用整数记录，账户可用余额不得低于0；账本汇总与余额一致。
- NFR-02 一致性：成功兑换必须**同时**完成积分借记、商品库存减少、订单与台账记录；任何步骤失败整体回滚。
- NFR-03 安全性：密码PBKDF2加盐哈希、JWT短期授权、按角色及资源所属校验。演示密码与密钥不得用于生产。
- NFR-04 可维护性：模型、路由、业务服务分层；提供OpenAPI；基础测试与GitHub Actions。
- NFR-05 可移植性：本地SQLite开箱即用；部署示例 MySQL 8 + Docker Compose（未在当前环境实测）。
- NFR-06 可用性：网页适配桌面与移动屏；缺乏无障碍专项审计，不宣称达到WCAG标准。

## 6. 核心业务计算约束

教学模拟汽车排放基准180g/km，公交70g/km，地铁40g/km，骑行与步行0g/km。`saved_g=floor(distance_m*(180-mode_g/km)/1000)`；`points=floor(saved_g/100)`。非核证碳因子，取整与输入规则详见README。

## 7. 四轮Sprint计划（建议每轮1周）

| Sprint | 目标 | 完成定义DoD | 可工作增量 |
|---|---|---|---|
| S1 | 确定范围及底座 | 用户故事、用例图、登录、健康检查、ORM实体 | 可登录、可看商品列表 |
| S2 | 行程与积分闭环 | 核算规则、幂等性、事件与台账测试通过 | 可上报并取得积分、查记录 |
| S3 | 商城与商户 | 兑换原子事务、履约与清算流程 | 可从出行到兑换再清算 |
| S4 | 稳定与交付 | 集成/并发测试、部署文档、报告与演示材料 | 可复现完整业务链 |

**注意**：上表是课程建议计划，不是声称已经开展了四次真实小组Sprint。真实会议时间、完成者、评审及回顾由组员实际补充。
