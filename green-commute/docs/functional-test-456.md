# 第4、5、6项功能测试

本次补充《测试报告》第3部分中第4、5、6项对应的16条功能测试。每项记录表分别从1编号，测试脚本中的名称与记录编号对应。

| 报告分项 | 测试脚本编号 | 覆盖内容 |
| --- | --- | --- |
| 4 积分商城、兑换与退款 | `test_4_01` 至 `test_4_06` | 兑换成功、积分不足、退款、重复退款、核销后退款、最后一件商品并发兑换 |
| 5 商户商品、品类与库存管理 | `test_5_01` 至 `test_5_06` | 发布商品、补货、重复补货、无效库存调整、空白商品名称、商品上下架 |
| 6 商户订单与核销 | `test_6_01` 至 `test_6_04` | 商户订单查询、首次核销、重复核销、居民越权访问 |

## 运行

在 `green-commute` 目录中安装项目测试依赖后运行：

    pytest tests/test_functional_456.py -q

`tests/conftest.py` 在导入应用前配置独立的临时 SQLite 数据库；测试使用演示种子账号，测试函数之间重建数据库状态。不要把测试脚本指向真实业务数据库。

2026年11月17日在隔离测试环境运行上述脚本，结果为16项通过。项目当前还包含其他测试，本说明只统计本文件的16项。
